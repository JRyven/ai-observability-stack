# Contributing

Thanks for your interest in improving this project.

Code edits, documentation improvements, examples, bug reports, and pull requests are welcome for review. A maintainer may ask for changes before accepting a contribution.

Before submitting a change:

1. Keep examples and configuration generic. Do not commit private hostnames, usernames, machine paths, credentials, tokens, or organization-specific data.
2. Run the available verification script:

   ```bash
   bash scripts/verify.sh
   ```

3. Include a brief description of what changed and how you validated it.

This repository does not currently define a formal governance process. Contributions are reviewed on a best-effort basis.
